# Python Dasar

Repositori ini berisi catatan dan latihan pembelajaran dasar pemrograman Python, mulai dari pengenalan sintaks hingga konsep *Object-Oriented Programming* (OOP), penanganan *error* dan *file*, serta modul dan *package*.

## Daftar Materi Pembelajaran

Materi disusun berurutan dari tingkat dasar hingga lanjutan:

1. **Hello Python** — Program pertama dan pengenalan dasar Python.
2. **Learn Python Basic Structure** — Struktur dasar penulisan kode Python.
3. **Learn Python Basic Data Types** — Tipe data dasar di Python.
4. **Learn Python Variables** — Penggunaan dan aturan penamaan variabel.
5. **Learn Python Constants** — Konsep konstanta dalam Python.
6. **Learn Python Operators** — Operator aritmetika, perbandingan, logika, dan lainnya.
7. **Learn Python Control Flow** — Percabangan (`if`/`elif`/`else`) dan perulangan (`for`/`while`).
8. **Learn Python Functions** — Pembuatan dan pemanggilan fungsi.
9. **Learn Python Lists, Tuples, and Sets** — Struktur data koleksi dasar di Python.
10. **Learn Python Dictionary** — Penyimpanan data berbasis pasangan *key-value*.
11. **Learn Python Classes and Objects** — Pengenalan kelas dan objek dalam OOP.
12. **Learn Python Encapsulation** — Pembungkusan data dan pembatasan akses (*encapsulation*).
13. **Learn Python Inheritance** — Pewarisan sifat antar kelas (*inheritance*).
14. **Learn Python Polymorphism** — Penerapan polimorfisme pada OOP.
15. **Learn Python Abstraction** — Abstraksi kelas dan metode (*abstraction*).
16. **Learn Python Exception Handling** — Penanganan kesalahan (*error*) saat program berjalan menggunakan blok `try`/`except`.
17. **Learn Python File Handling** — Membaca, menulis, dan mengelola *file*.
18. **Learn Python Modules** — Mengorganisir kode ke dalam modul dan mengimpornya.
19. **Learn Python Packages** — Mengelompokkan modul ke dalam *package*.
